    Cloudflare Zero Trust Tunnel

    Checking...

    Cloudflare Tunnel allows you to expose TermuxPanel and all hosted websites to the internet securely via HTTPS without port forwarding or dynamic DNS.

    Option 1: Semi-Automatic (Paste Token)

    Create the tunnel in your Cloudflare Zero Trust Dashboard and paste the tunnel token below. Stored securely in ~/termux-panel/config/cloudflare-token (chmod 600).

    Option 2: Fully-Automatic (Cloudflare API)

    Enter your Cloudflare API Token and domain name. TermuxPanel will automatically create the tunnel, configure ingress routes, and create DNS CNAME records for you.

    Result: https://panel.yourdomain.com

    🛡️ 2nd Layer Security: Cloudflare Access

    RECOMMENDED

    Require your personal Google Login or One-Time Email PIN code before anyone can even see your TermuxPanel login screen.

    1. Go to Cloudflare Zero Trust ➔ Access ➔ Applications ➔ Add an application.
    2. Select Self-hosted ➔ Set Application domain to panel.yourdomain.com.
    3. Under Policies, set Action to Allow and add your email under Include Emails.
    4. Click Save application.
